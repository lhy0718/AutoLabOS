# Live Validation Milestone

The full interactive workflow has been exercised as a governance validation.
The milestone demonstrates that AutoLabOS can preserve measured artifacts,
route blocking findings upstream, and end honestly with a downgraded or blocked
paper-readiness decision.

This record is not empirical evidence for a research claim and does not name a
particular model, benchmark, run identifier, machine, or condition grid. Those
details belong in governed run artifacts, not reusable repository guidance.

The reusable contracts are maintained in:

- `docs/research-brief-template.md`
- `docs/tui-live-validation.md`
- `docs/live-validation-playbook.md`
- `docs/experiment-quality-bar.md`
- `docs/paper-quality-bar.md`
- `docs/reproducibility.md`
- `docs/live-validation-issue-template.md`

Future live validation must begin from a governed brief, exercise fresh and
resumed sessions, preserve failed attempts, and run the paper-readiness audit.
Workflow completion or PDF generation alone cannot satisfy the milestone.
